## 👋 About me

I'm a full-stack developer from the Philippines who likes owning the whole stack — the UI people tap on, the database that keeps the money right, and the hosting, CDN and domains in between.

- 🚀 Shipping and running **multiple live Next.js + Supabase apps** in production
- 🗄️ Comfortable deep in **Postgres** — RPCs, row-level security, cron jobs, query tuning
- ☁️ Deploys on **Railway / Render / Vercel**, fronted by **Cloudflare**
- 📱 Wrapping web apps as **Android & iOS** apps
- 🎨 Background in video & design — Premiere Pro, After Effects, Photoshop
